# DadhiCutting — Professional 18-screen Figma import pack

18 separate full 390×844 SVG mobile screens, each with vector text, buttons, cards, and line icons. 18 PNG previews are included for review, plus an overview board.

## Import to Figma
1. Create a new Figma design.
2. Drag `SVG/*.svg` files onto the canvas; optionally frame each at 390×844.
3. Create Figma components, Auto Layout, variables and prototype connections as a separate design-system pass.

## Important notes
- These are newly constructed vector mockups, not a native `.fig` file.
- The user's supplied image is a *logo-kit preview collage*, not original vector paths; `Brand/DadhiCutting_Vector_Logo.svg` is a faithful-in-spirit simplified vector interpretation. It is not a traced exact reproduction.
- Prices, names, financial totals, and business details are illustrative.
- Icons are simple vector stroke illustrations for editable mockup use.
- No photo content is embedded in these editable screens; avatars are vector monograms.
